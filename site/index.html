Kanban as Code v0.1 draft, RFC

Your Kanban system, in plain markdown files

Kanban as Code is a draft standard for how to structure work items, workflow and transitions in markdown. The files live in your repo, next to the people and agents doing the work, and any tool can read them.

The standard

A first draft is out for comment. It builds on the Kanban Guide and on what we learned building flow metrics into Lighthouse, and it comes with use cases: which tools read the files, which visualizations they make possible, and why you would want them.
