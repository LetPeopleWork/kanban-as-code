# Examples

| Example | Status | What it shows |
| --- | --- | --- |
| [`single-team`](single-team/) | Core | A made-up web shop team: one workflow with three `doing` states, ten cards. One card went back from Live (only its second Live counts), one went from Next straight to Live (no start date), one is blocked. |
| Several teams | Planned | One tool reading several workflow files. |
| Several repos | Planned | One board whose cards live in more than one repo, with `sources`. |
| More than two levels | Planned | Portfolio cards as parents of team cards, with `parent`. |

The single-team example is deliberately simple. The others come later. The files are an example, not real data.
