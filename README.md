# Kanban as Code

A draft standard for keeping a Kanban system in plain markdown files, so any tool can read the same files.

Status: v0.1 draft, RFC. Read [SPEC.md](SPEC.md) and tell us what is wrong with it.

Site: https://kanban-as-code.letpeople.work

## What is in this repo

| Path | Content |
| --- | --- |
| `SPEC.md` | The standard |
| `kanban/` | This repo's own board, the first example |
| `examples/` | Sample boards and work items |
| `skills/` | Setup skills for agents |
| `tools/` | Small helpers that connect tools to the files |
| `site/` | Source of the website, deployed by GitHub Pages |
